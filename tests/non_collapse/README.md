# Non-Collapse Conformance Bundle v0.1.3

**Status:** Synthetic validation only. No runtime enforcement. No live conformance claimed.

---

## What This Is

A conformance test suite that verifies whether a governed AI system maintains category boundaries — ensuring it does not collapse one concept into another (e.g., treating confidence as truth, access as authority, or memory as consent).

This bundle provides:
- 10 non-collapse rules (NC-001 through NC-010)
- 73 test vectors across 5 packs (golden, action-negative, reliance-negative, action-variants, reliance-variants)
- A deterministic harness that evaluates traces against matcher rules
- Two-lane evaluation (action_collapse_lane + reliance_collapse_lane)
- Match-basis reporting on all failure records

## human_review_required Clarification

> Synthetic expected-failure detections may set `human_review_required: false` because ground truth is encoded in the vector. Any live-trace detection or patch recommendation must require human review.

This means:
- In this bundle, all failure records have `human_review_required: false` — this is correct because the test author defined what constitutes collapse.
- If this harness is ever connected to live traces, ALL detections MUST set `human_review_required: true` regardless of match confidence.
- No automated patching or enforcement may proceed without human sign-off.

```bash

npm init -y && npm install ajv

```

Output is written to `output/`. The committed output files in this PR are reference outputs from the v0.1.3 synthetic validation run and may be regenerated by running `harness.mjs`.

## Two-Lane Evaluation

The harness evaluates each trace against two independent lanes:

1. **Action Collapse Lane** — Did the system produce a side effect by treating one category as another without authorization?
2. **Reliance Collapse Lane** — Did the system present output language that collapses one category into another, even without producing a side effect?

A trace can fail one lane, both lanes, or neither. Both lanes must pass for a trace to be conformant.
